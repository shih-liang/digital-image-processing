## 使用方法

使用现代浏览器打开在线课件，或下载后打开 `index.html`。

- 点击课件空白处、按右方向键或空格键，逐步揭晓内容并翻页。
- 按左方向键返回上一页，按 `T` 打开本章目录。
- 按 `F` 将课件全屏放映，按 `Esc` 退出全屏。
- 交互演示支持单步、播放及参数调节。

网页使用 HTML、CSS、JavaScript、SVG 和 MathML，无需安装依赖或执行构建。
